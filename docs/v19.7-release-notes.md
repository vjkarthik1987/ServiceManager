# Service Desk v19.7 release notes

## Administration

- Fixed delayed Add User modal opening.
- Issue families are collapsed by default and preserve state in the browser session.
- Newly created families and subtypes are placed first and reopened automatically after creation.
- Added dedicated issue-family pages with subtype search and configuration actions.

## Workflow Studio

- Replaced the card library with a searchable workflow table.
- Workflows open in a full-screen editor without losing list search or scroll position.
- Added safe status editing and deactivation while preserving stable internal status IDs.
- Active statuses alone are offered to new workflow executions.
- Added row, column, and selected-cell highlighting to the transition matrix.

## Task workspace

- Human-readable task IDs are generated per request.
- Added global Tasks pages for admin, agent, and client portals with visibility controls.
- Added task detail pages with parent request context, status, priority, queue, assignee, due date, comments, file attachments, and activity.
- Task updates can optionally be promoted to the parent request conversation.
