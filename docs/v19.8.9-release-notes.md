# v19.8.9 release notes

Built on v19.8.8 / the v19.8.5 workflow engine.

## UX and ownership
- Minimal centered tenant/admin login with only a heading, form, forgot-password link, and reduced-motion friendly ambient animation.
- Support journey and workflow progress moved into the issue hero, directly beneath the request key/title.
- Comments & updates and Audit trail are now tabs in one Activity area.
- The right control rail fills the viewport, stays sticky on desktop, and scrolls independently.
- Support-routing actions now sit inside Current Workflow rather than a separate card.
- Any eligible operational user can assign/reassign an active stage to another eligible peer for that same client/support level; Take ownership remains available.
- Profile-specific primary actions are brighter and use subtle hover/lift effects.

## Compatibility
No destructive database migration is required. Re-provisioning is not required solely for v19.8.9.
