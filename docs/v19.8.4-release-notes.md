# Service Desk v19.8.4 release notes

## Identity and access
- Email uniqueness is scoped to an organization/tenant. The same normalized email may exist in separate tenants.
- Client/partner/agent ServiceUser email changes use a one-time verification link before the login changes.
- Tenant-admin email changes remain verified and matching admin/service identities stay aligned.
- Tenant-admin mode disables client assignment controls in the user form.
- Users is a single tabbed table: All, Client Users, Partner Users, Agents, Managers, Engagement and Tenant Admins.

## Client administration
- Client detail now includes Overview, Users, Configuration, Operational Rules and Hierarchy tabs.
- Users lists direct and inherited access for the selected client and links back to the shared global editor.

## Help
- Help & FAQ now begins with definitions for issue, issue family, subtype, L1/L2/L3, workflow, support path, status, task, blocking task, SLA, OLA, severity, priority, Bank to Verify, RCA and closure approval.
- Role-specific guidance is grouped separately and search remains available.

## Geography
- Add Region and Add Subregion stay visible as primary actions. Seed Defaults is under a compact More menu.
- A dedicated optional geography-layer divider separates Subregions from Regions.

No destructive migration is required. Existing v19.8.3 data remains compatible.
