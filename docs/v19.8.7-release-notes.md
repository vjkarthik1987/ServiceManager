# Service Desk v19.8.7

> This release is built **directly from v19.8.5**. It does not include the v19.8.6 request-runtime experiment.

## Request workbench

- Jira-inspired three-zone layout: permanent navigation sidebar, central issue workspace, sticky right action rail.
- Prominent request key and title, with client/family/subtype/environment/support metadata immediately below.
- Compact visual SLA strip with Response, Next update and Resolution health meters. Text due-times/time-left remain authoritative; colour is an additional visual cue.
- Description and issue metadata are denser and less card-heavy.
- Compact workflow/support path view.
- Workflow tasks are rendered as task rows instead of large cards; blocking work remains obvious.
- Conversation and history remain separate, with the conversation styled as the primary collaboration area.
- Status choices are shown in the right action rail. Selecting a target and pressing Continue opens the existing audited transition dialog, preserving comments and all v19.8.5 workflow rules.
- Push to L2/L3/parallel support remains a distinct support-routing action rather than being disguised as a workflow status.

## Profile-aware UX

Profiles now receive different navigation emphasis and accent schemes while keeping a common component language:

- Tenant Admin — SunTec green
- Client User — calm slate blue
- Partner / L2 — amber
- SunTec Agent / L3 — purple
- Agent Manager — teal
- Engagement Manager — burgundy

Semantic colours such as SLA green/amber/red are not replaced by profile accents.

## Help

Help & FAQ now explains the request workbench, the reason profile navigation differs, and how to read the visual SLA strip.

## Compatibility

No database migration is required. No workflow, support-path, SLA, client-family, provisioning or request-execution semantics from v19.8.5 were intentionally changed.
