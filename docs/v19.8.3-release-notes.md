# Service Desk v19.8.3

## Organization and identity
- Simplified `/setup` to a centered enterprise form.
- Pre-validates the first administrator email and reuses pending setup records safely.
- Verified administrator email-change flow with one-time token and old-address notification.
- `MAIL_MODE=console` is strictly console-only.
- Password confirmation gets live match/length feedback.

## Navigation and help
- Grouped sidebar by Overview, Operations, Customers, Service Design, Configuration, Administration, Personal and Help.
- Added searchable role-aware Help & FAQ pages after login.

## Geography
- Added optional Subregion under Region.
- Region/Subregion configuration includes preferred timezones.
- Timezone lists show friendly city/UTC-offset labels and search filtering.
- Client timezone choices are constrained to the selected region/subregion.
- Client configuration now calls the section “Location & environments”.

## Configuration UX
- Duplicate environment/reference codes return visible same-page validation errors.
- Two-character environment codes remain valid.
- Severities, priorities and products expose quick deactivate/reactivate actions.
- Products support multi-line/comma-separated bulk module creation.
- Newly created clients return to the client list and are highlighted.
