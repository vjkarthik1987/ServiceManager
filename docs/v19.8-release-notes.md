# Service Desk v19.8

## Administration and performance
- The Users page now renders one reusable edit dialog instead of one full client-assignment form per user.
- Add User opens immediately and user create/edit submits asynchronously.
- Validation errors remain inside the user dialog and preserve entered values.
- Invitation email and audit delivery no longer block the user save response.
- User status dots and labels are aligned as a single status unit.

## Workflow Studio
- The workflow library uses one reliable full-screen editor dialog with an immediate loading state, cached reopen, and explicit reload action.
- Statuses can be inserted between visual workflow boxes using the plus control.
- Optional automatic rewiring replaces the direct neighbour transition with previous → new → next while preserving unrelated branches.
- The transition matrix continues to highlight the active source row, target column, and selected cell.

## Request and task experience
- SLA journey arrows are vertically centred between milestone cards.
- The task detail page now groups task purpose, ownership, request context, dates, and visibility into a clearer operational layout.

## Upgrade
No database migration is required. Existing organizations, clients, users, workflows, requests, task templates, generated tasks, and audit history remain in the configured MongoDB database.
