v30.99.1 — Chatbot Intent + Filter + Title Accuracy

Focus:
- Fix count questions that mention multiple exact statuses, for example: status either as NEW or OPEN.
- Preserve plain “open issues” as the active/open issue bucket unless the user explicitly asks for exact status filtering.
- Keep Jira pending separate from open status logic.
- Apply entity acronym mentions such as SPRBNK together with count/list filters.
- Add category and request type extraction to issue query filters.
- Improve smart issue title generation so long descriptions do not become truncated titles.
- Map critical/high wording to configured severities such as S1/S2 when tenant severity options use S-level labels.

Examples expected:
- “How many issues are there which have status either as new or open?” -> counts status IN [NEW, OPEN].
- “How many open issues are there?” -> counts active/open bucket.
- “How many issues are Jira pending?” -> counts Jira push pending/queued/not-pushed logic, not open issues.
- Long ERP integration description -> generates a short operational title such as “ERP / REST API Sync Failure Causing Inventory Mismatches”.
