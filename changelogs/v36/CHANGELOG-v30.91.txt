# v30.91

Assistant hardening release on top of v30.90.

## Fixed
- Treats “raise/create/open/log a new issue” as intent only, never as the issue title or description.
- After client/entity selection, asks for the actual issue description instead of prematurely confirming creation.
- Accepts slightly malformed entity selections such as missing closing brackets, e.g. `Standard Bank (STDBNK`.
- Requires meaningful title and description before confirmation.
- Confirmation now includes Description, so users can review the actual issue content before creation.
- Filters weak OpenAI extraction output so generic commands are not converted into issue fields.

## Improved
- More robust entity matching across name, path, acronym, compact text, and partial words.
- Better missing-field prompts that ask for the real problem, place, and impact.
- Safer assistant conversation state for customer-update, escalation, and report-answer drafts.
- OpenAI system instruction now explicitly forbids treating commands as content.

## Operational note
Set `OPENAI_API_KEY` and optionally `OPENAI_MODEL` in `.env`. The deterministic guardrails still run even when OpenAI is enabled.
