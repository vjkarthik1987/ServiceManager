v30.97.3 — Chatbot count-answer intelligence

Changes:
- Added deterministic handling for issue count questions such as "How many issues are there?".
- Count-style questions now return a compact numeric answer instead of a full issue list.
- Count answers respect the same role/entity/customer-visibility scope as issue search.
- Supports filtered counts such as open issues, assigned-to-me issues, breached issues, high-severity issues, waiting-for-client issues, and updated-today issues.
- Keeps existing list behavior for explicit list/show/display requests.

Example:
User: How many open issues are there?
Assistant: There are 12 open issues in your permitted scope.
