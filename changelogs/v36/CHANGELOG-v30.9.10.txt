v30.9.10
1. Fixed issue creation failure caused by IssueCounter acronym validation still enforcing 4 characters. IssueCounter now supports 6-character entity acronyms consistently.
2. Added first Reports module with scope-aware reporting for the logged-in user.
3. Reports included:
   - SLA compliance by severity
   - Issue creation trend
   - Issue volume by type
   - Issue volume by severity
   - Status aging / bottleneck report
   - Agent performance report
   - Jira execution report
   - Client/entity breakdown report
4. Reports support a date-window selector (7/14/30/60/90/180/365 days).
