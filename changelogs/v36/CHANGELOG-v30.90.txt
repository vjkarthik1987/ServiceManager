# v30.90

OpenAI intelligence layer built on v30.80.

## Added
- OPENAI_API_KEY, OPENAI_MODEL, and OPENAI_TIMEOUT_MS environment support.
- Optional OpenAI-backed assistant intent extraction with safe deterministic fallback.
- Better smart issue creation field extraction using accessible entity context and tenant issue masters.
- AI-enhanced issue summaries using only scoped issue facts and visible comments.
- Customer-ready update draft generation that avoids internal-only comments for client users.
- Internal escalation draft generation for agent, agent manager, and superadmin roles.
- Natural-language report answers over scoped issue results.

## Safety and compatibility
- No OpenAI key is required; v30.80 behavior continues through local rule-based fallbacks.
- OpenAI failures/timeouts do not break the assistant flow.
- Client users remain restricted to permitted entity scope and customer-visible data.
